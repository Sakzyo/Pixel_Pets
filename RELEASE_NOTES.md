# Desktop Pets 1.0.1

Native, offline desktop companions for macOS 14 and later.

## What's new

- Pet names appear above desktop animals and update when renamed in Manage Pets.
- Unlimited feeding, with no treat quota or refill countdown.
- Lifelike artwork for all five Realistic dog coats, across 30 animations. Dogs face their direction of travel.
- Existing pet identities, names, coats, roster order, visibility, style selection, and settings are preserved when updating from 1.0.0.

The app still includes 16 species, 40 Realistic variants, 35 Pixel variants, and
450 animations. Pixel artwork and other species are unchanged by this update.

## Download, install, or update

Download `Desktop-Pets-1.0.1-universal.dmg` and open it.

1. Quit Desktop Pets from the paw menu if it is running.
2. Drag **Desktop Pets.app** to **Applications**, choosing **Replace** when updating.
3. Eject the disk image and reopen Desktop Pets from Applications.

On the **same Mac and macOS user account**, your pets and preferences are stored
separately from the app at:

```text
~/Library/Application Support/DesktopPets/state.json
```

Version 1.0.1 keeps the same storage location, bundle identifier, and save format
as 1.0.0. Replacing the app does not replace this file. The DMG contains no saved
roster or reset script. Keep the `DesktopPets` Application Support folder when
updating; copying `state.json` elsewhere beforehand is an optional backup.
Older saves that lack newer settings continue to load with the existing defaults.
Unreadable or incompatible save files are left untouched rather than overwritten.

The DMG includes Apple silicon and Intel binaries. Its SHA-256 checksum is
supplied alongside it. Artwork, source, and generation prompts are in the repository.

## Verification and signing

The 16 automated tests pass, including a save generated by the actual v1.0.0
encoder: all seven test pets, their identifiers/order/coats/visibility, and every
saved setting survive loading, editing a setting, and relaunching the store.
Other checks cover empty rosters, older saves, corrupt-file preservation,
unlimited feeding, and all 450 GIFs.

The DMG is checked for integrity, checksum, both architectures, version 1.0.1
(build 2), signature validity, and bundled artwork hashes. An app copied from the
mounted image is launched using an isolated v1.0.0 save to check startup without
altering the real user's pets.

**This release is ad hoc signed and is not notarized.** No Developer ID signing
certificate is available on the build machine. macOS Gatekeeper may block the
app after download; this is not a Developer ID signed distribution.

Dog artwork and name badges were inspected using offscreen rendering. Live
interaction across Spaces, full-screen apps, Stage Manager, and multiple displays
remains unverified. The Intel binary is compiled but has not been run on Intel
hardware. See [COMPATIBILITY.md](https://github.com/Sakzyo/Pixel_Pets/blob/v1.0.1/COMPATIBILITY.md)
for the detailed verification boundaries.

## Rebuild

Run `./script/test.sh`, then `./script/package_dmg.sh`. The packaging script builds
the universal Release app, creates and verifies the compressed DMG, and writes
its checksum under `dist/`. Both build paths read their version from
`Config/Info.plist`; the save format version remains independent of that number.
