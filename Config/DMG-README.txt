Desktop Pets

Requires macOS 14 or later. Includes Apple silicon and Intel binaries.

Installation
1. Quit Desktop Pets using the paw menu if it is already running.
2. Drag Desktop Pets.app to the Applications shortcut. Choose Replace when updating.
3. Eject this disk image.
4. Open Desktop Pets from Applications.
5. Use the paw icon in the menu bar to choose Manage Pets.

Updating and your saved pets
On the same Mac and macOS user account, replacing the app preserves existing
pets and settings. Version 1.0.1 uses the same save location and format as 1.0.0:
~/Library/Application Support/DesktopPets/state.json
The DMG contains no save file and does not reset this folder. Keep the folder
when updating. You can copy state.json elsewhere as an optional backup.

Choose Realistic or Pixel in the Pets tab. Visit Shelter offers species,
coat colors, and names. Closing the manager leaves the pets running;
use Quit Desktop Pets in the paw menu to exit.

Signing
This release is ad hoc signed and is not notarized. It does not have an
Apple Developer ID signature, so macOS Gatekeeper may block it after download.

Artwork credits are included inside the app and on its Credits tab.
